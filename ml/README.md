# Mockly - Machine Learning Models Directory

This directory is reserved for future Machine Learning pipelines, including:
- Whisper (Speech-to-Text transcription)
- Random Forest (Classification & score modeling)
- Sentence Transformers (Semantic similarity & answer relevance)
- Audio feature extraction (pitch, pause detection, speaking rate, hesitation, filler words)

> **Note**: ML analysis is not implemented yet. It will be added in later development phases.
